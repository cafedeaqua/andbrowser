Intel Edison + Intel Edison Kit for Arduino + GROVE スターターキットの更新方法

久しぶりにIntel Edison + Intel Edison Kit for Arduino + GROVE スターターキットを触り始めたので、アップデート方法についてまとめておく。mac book pro 13inch yosemite の環境である。

現在のEdisonのファームウェアバージョンの確認方法

consoleにserialで接続します。以下のコマンドで確認できます。

私の環境の場合は、以下のコマンドで接続できます。

screen /dev/tty.usbserial-AJ035GT1 115200

つづいて、現在のファームウェアバージョンを以下のコマンドで確認します。


root@edison:/etc/opkg# cat /etc/version
edison-rel1-maint-weekly_build_16_2014-10-14_14-56-19

2014/12/29時点の最新ファームは Revision 006 の　2014/10/24 バージョンのようです。ファームウェアとドキュメントの更新日が必ずしも同じとは限らないので、ファームウエァバージョンはこの日よりも以前のものだと思われます。

最新のファームウェアイメージは、https://communities.intel.com/docs/DOC-23242からダウンロードできます。このリンクの
「Edison Yocto complete image」のzipアーカイブをダウンロードします。以下のコマンドで edison をマウントしたディスクのファイルを削除し、ダウンロードしたアーカイブの中身を展開します。（ただし、edisonを最初にマウントしたときは、FAT16のため　FAT32にするために　Finderから右クリック→情報を見るのパーティションからフォーマットしましょう。詳細は、こちらの記事に丁寧に説明がありますのでご参照ください。私も大変役に立ちました。ありがとうございました。

すでにフォーマットされていて、古いデータが残っている場合は、以下のコマンドですべて削除して、ダウンロードしたzipアーカイブを解凍したファイルを入れてください。

$ cd /Volumes/Edison
$ rm -rf *
$ rm -rf \.*

つづいて、console にログイン(root のみの入力で良い)して、以下のコマンドでファームアップを実行します。


$ reboot ota
