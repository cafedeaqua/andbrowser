admin to development  

CNETでtogmailアプリ紹介

[CNET Japan][ビジネスアプリセンター][Android] 決まった宛先にすばやくメールが送れるアプリ「toGmail」という記事でtogmailアプリをご紹介頂きました。

本アプリの開発意図を汲み取ったうえで紹介して頂き大変うれしかったです。ライターの山口真弘さんに感謝申し上げます。記事のなかでいくつかアプリへの要望を頂いたので整理させて頂きました。現在のシンプルな動作に影響がでないように検討を重ねたうえで将来の開発ネタとしていきたいと思います。

  • 複数の宛先をプロファイルとして設定
  • 複数プロファイル設定の場合に「共有」の選択画面に「# togmail profile1」「# togmail profile2」のように表示
  • 複数プロファイル設定の場合に「共有」->「#togmail」選択後、profile1, profile2 の選択ダイアログを表示
  • タイトルのカスタマイズ設定（受信メーラの振分に活用など）（Ex. 「タイトルは、%title です。」、 「[FYI] %title 」、「[twitter info] %title 」)
