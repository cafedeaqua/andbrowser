03.10.13 Androidアプリのadmob収益の受領方法

admin to Android SDK, development — Tags: admob, Android, paypal  

admobの収益が受け取れない

Androidアプリに admob 広告を掲載していて、支払先をにはPaypal を選択していました。今年の2月に初めて支払いの案内が以下のようにありました。（写真は3月となっていますが、2月にも同じ案内がありました。）

がしかし、一向に paypal の残高に反映されませんでした。さすがに1か月立っても反映されないため、調べてみました。同じように困ってる人も以下のようにいるようでした。

受け取れない原因

調査したところ、paypalアカウントには以下の３つの種類があり、admobの支払いを受け取るにはプレミアにしなければならないようです。アカウントを作成すると最初はパーソナルで、ある手続きを行うとプレミアになれるそうです。ただ、今回この手続きが色々と手間取ったのでここにメモっておきます。

  1. パーソナル
  2. プレミア
  3. ビジネス

プレミアに変更方法

まずこれが結構な手間がかかりました。プレミアにするには、以下の画面の「アップグレード」を選択します。

アップグレードするためには、以下の２つのことを実施することが必要です。まず以下の赤で囲んだところで「本人確認書類の提出」を行います。

  1. 本人確認書類の提出
  2. 暗証番号の入力

paypalからの連絡

本人確認書類の提出は、pdfで可能なので、私は運転免許証をデジカメで両面を撮影してパワーポイントに張り付けてpdfで出力したものを、フォームから添付で申請しました。これで暗証番号がメールで届くのかなと思っていたところ、以下のようなメールの連絡がありました。

誠に申し訳ございませんが、お客様のアカウント制限解除はまだ完了しておりません。
理由といたしましては、以下の点をご確認の上、ご協力をいただきますようお願いいたします。

この度は運転免許証をご提出いただき、誠にありがとうございました。

1.アカウントにご登録いただいているお名前は
ローマ字表記となっておりまして、ご提出いただいた運転免許証の言語表記方法とは異なっております。

これらは完全に一致する必要がございますので、恐れ入りますが、
アカウントにご登録いただいているお名前を運転免許証通りに
ご変更いただけますでしょうか。

なお、お名前の変更につきましては、お客様ご自身で変更することは出来かねます。弊社までご連絡いただきますよう、お願いいたします。

お電話でご連絡いただく場合、音声ガイダンスに従い、電話機の1（アカウント認証）を押してから、
1（本人確認のお問い合わせ）を押していただきますようお願いいたします。

2.ご提出いただいた運転免許証のご住所と
アカウントにご登録いただいているご住所が異なっているようです。

運転免許証上：漢字で表記　マンション名なし
アカウント上：ローマ字で表記　マンション名あり

大変恐れ入りますが、アカウントの住所を漢字に変更してから、
下記のいずれかの方法でご訂正をお願いいたします。

●アカウント上の「マンション名」の削除をご希望の場合、
アカウントにご登録いただいたご住所の「マンション名」を削除していただきますようお願いします。
この場合、現状の書類にて進行させていただきますので、再提出していただかなくても結構です。
＊注）ビル名を削除した場合、正確に書留ハガキが届かない場合もございますので、届くことを
確認した上で、修正いただきますようお願いいたします。

要約すると以下の2つを修正しないと、プレミアにアップグレードできないということです。
私は Paypal アカウントを作成するときに海外からの買い物に利用するだろうと考え、名前、住所などを英語表記で記載していました。
これが以下の問題を引き起こすことになりました。

  1. Paypalの登録の名前と免許証の名前が英字と漢字で異なる(*1)
  2. Paypalの登録住所と免許証の記載がマンション名の有、無で異なる

但し、(*1)のPaypalの登録の名前を英字表記にしていたものを漢字表記に変更するためには、インターネットからはできずに電話でしかできません。
電話番号を得るためには、paypalにログインする必要があり、ログインして「一時お問い合わせ番号」をゲットする必要があります。

上記を選択して、ログインすると以下のような一時お問い合わせ番号をゲットできます。これを手にいれてからその下にある電話番号に電話しましょう。フリーダイヤルも用意されているということで好印象です。

電話して「一時問い合わせ番号」を入力すると、オペレーターさんがでます。オペレーターさんは個人的な感想でいうと海外の方のようでした。日本語は堪能で少しイントネーションの違いはわかりますが、こちらの言っていることはすべて理解してくれているようなので問題はないと思いました。
電話でしながら、まず住所を運転免許証と同じになるように修正します。修正完了したことを電話で伝えると、オペレータさん側でも確認できました。
あとは、名前をオペレーターさんに伝えたところ、英字表記の名前を漢字表記（運転免許証）に変更してもらえました。正しく変更されたかどうかを確認してみると、（名前）（苗字）の表記になっていて、日本人の私から見ると漢字でこの順序で記載されているのは違和感がありますが、paypalの仕様だと思いますので仕方ないですね。我慢しましょう。英語表記ならこの順番でも違和感ないんですけどねぇ。

余談：Androidアプリでの言語ごとの文字列対応

Androidアプリの場合は、以下のような xml 定義を言語ごと用意して解決できますね。

res/value-ja/string.xmlへの記載


    名前：%2$s %1$s
res/value/string.xml(英語用)への記載


    NAme: %1$s %2$s
コード例
String first_name = "名前";
String family_name = "苗字";
String myaccount_name  = String.format(getString(R.string.myaccount_personal_name), first_name , family_name );

電話後の対応

電話で情報を修正できたあとは、郵送で暗証番号が送られてくるそうなので、それを入力すれば晴れてプレミアになれます。
これでadmob の収益が受け取れるようになります。まだ届いてないのですが受け取るのが楽しみです！
