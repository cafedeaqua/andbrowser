Deploygate Bakusoku Iterations Tokyo 1に参加

Bakusoku Iterations Tokyo 1に参加してきました。この会は、DeployGateが主催する「アプリ開発サイクルをより高速に回すためのノウハウを共有する勉強会」です。Deploygate は以下のようなコンセプトの開発中アプリのテストやドッグフーディング向けのアプリ配信サービスです。

開発中のアプリを、
一瞬で手元へ。

USBケーブルにさようなら。配布、ログ収集、アップデート、
すべてをワイヤレス、リアルタイムで。
