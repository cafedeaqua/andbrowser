06.06.14 github製エディタ Atom for Windows 入手方法（非公式ビルド）

admin to git  

github The Hacker editor Atom

githubから The hackable editor Atom というエディターが公開されました。早速利用してみようと思ったのですが、まだ Mac 向けの Build しか提供されていませんでした。WindowsやLinuxで利用したい場合は、以下のように自分で Build しなければません。

Atom for Windows(非公式版）

がしかし、さすがインターネットの世界、既に Build したものを提供してくれているサイトがあります。
http://atom.someguy123.com/#sthash.qFfvJCrT.dpbs
のサイトで Stable版（安定版。ただし古いビルドの可能性あり）、Unstable版（不安定版。ただし最新ビルド）のビルドが提供されています。もちろん、非公式のため、サポートなどありませんし、Stable版といいながらもうまく利用できない場合もありますが、それは覚悟のうえでご利用ください。

ひとまず、上記の「Download Latest Stable Build(.zip)」を選んでダウロードします。ダウンロードは、MEGA というファイル配信・共有サービスを利用します。

2014/06/06時点で Atom 0.99.0-ea0773e.rar がダウンロードできました。これを解凍すると、以下のようにファイル群が得られます。

解凍したファイルの中から、atom.exe を実行すると以下のように起動できました。

トラブルシューティング

エラー「MSVCP100.DLL が見つかりません」がでる場合

32-bit MSVC 2010 Runtimeをダウンロードしてインストールしてください。

ファイルパスが長すぎます

解凍した atom.exe が深い階層に置かれている場合に発生する場合があります。解凍したフォルダを C:\atom のような浅い場所に変更してください。

これを見た皆様がエラーなくご利用頂けることを祈っております。
